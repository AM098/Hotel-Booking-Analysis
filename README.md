# Hotel-Booking-Analysis
Hotel Booking Analysis (EDA)
An exploratory data analysis of hotel booking data for a City Hotel and a Resort Hotel.  The project looks at booking patterns, cancellations, pricing, and customer sources to find insights that can help hotels improve revenue and reduce cancellations

# Tools Used
  - Python (Pandas, NumPy)
  - Matplotlib and Seaborn
  - Jupyter Notebook

# Key Insights
  - Bookings: City hotels receive more bookings than resort hotels, while resort hotels tend to have a higher average daily rate (ADR), especially on weekends and holidays.
  - Monthly trends: August has the highest number of both confirmed and cancelled bookings. January has the lowest number of confirmed bookings and the highest     cancellation share.
  - Pricing and cancellations: Cancellations rise as prices rise, so room price is a major factor in cancellations.
  - Top country: Portugal has the highest number of cancelled reservations.
  - Booking channels: About 46% of guests book through online travel agencies, 27% through groups, and only 4% book directly.
